# Space Grotesk

The full variable WOFF2, Regular TTF and Medium TTF are original files from the [typeface author's public repository](https://github.com/floriankarsten/space-grotesk), retrieved October 18, 2026. The WOFF2 serves the interface through `next/font/local`; it was not extracted from the brand PDF.

The static SemiBold TTF was supplied by the [official Google Fonts CSS API](https://fonts.googleapis.com/css2?family=Space+Grotesk:wght@600). Its TrueType header and internal family/style were verified as `Space Grotesk` / `SemiBold`. Static 400/500/600 faces serve the server-side social-image renderer.
