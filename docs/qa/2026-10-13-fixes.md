## Additional fixes from frontend review

- Failed gallery images replace only the image pane, preserving access to remaining screenshots. Thumbnail buttons have names and selected state.
- Competition filters and badges honor manually closed status, including future deadlines.
- Event descriptions have an expand/collapse control, including events without an external URL.
- Project/profile upload state blocks button and implicit form submission until uploads settle. Chip changes, uploaded URLs and removals mark drafts dirty. Profile cover/avatar uploads are serialized.
- Post, mobile Explore, filters and feedback use Radix modal portals with names, Escape handling and focus management. The account-menu trigger has an explicit name.
- Closing/reopening feedback resets action state, so a prior successful local mocked send does not block the next session.
- Homepage featured cards use existing viewer vote/save membership rather than hardcoded unselected state. Existing query helpers are reused without inspecting their database implementation.
- Shared FormField replaces seven repeated helpers. Single controls receive associated labels and error descriptions; compound controls receive group names. Event-request, entry, comment and message fields also have associated labels or explicit names.
- Directory help links target new directory guidance in `/docs#directory`.
- Dirty forms now warn before internal links or branded Back discard a draft. Clean forms, hash links, modified clicks and new tabs are not blocked. Explicit Cancel retains its existing dialog, and full unload retains its browser warning. The guard unregisters when the draft becomes clean or the form unmounts.
- Budget/prize first-band copy now says "Up to $250", matching the existing inclusive filtering. Results and overlapping range semantics are unchanged; actual board tests cover $250, $251 and clearing.
- Removed the unreachable desktop NavLinks/PostMenu branches inside the mobile-only NavShell. Each child was hidden below `lg`, while its parent was hidden at `lg` and above. The actual desktop Sidebar and mobile navigation remain in place.

## Remaining review notes

- Actual signed-in dashboard/account flows, OAuth, mobile widths, touch behavior and visual regressions remain untested.
- Internal links and branded Back now protect dirty forms. Native browser Back/Forward and programmatic redirects outside those entry points remain a limitation of the current hook. A `popstate` listener cannot cancel a traversal; trapping history or persisting drafts would be a broader behavior change and needs deliberate design and real browser testing. No claim of full draft retention is made.
- Shared budget/prize endpoints remain inclusive. A $250 item can match adjacent bands, and a gig budget range can intentionally overlap several bands. The inaccurate "Under $250" label was fixed without changing the product's filtering semantics. This is not treated as a remaining actionable bug without evidence that exclusive bands are intended.
- Redundant navigation branches were removed. No separate navigation behavior change remains proposed.
- Backend authorization/enforcement and database state were outside this review. Closed-competition submission enforcement was not tested through a production mutation.

Review focused on public frontend routes, navigation, filters, forms, media, cards, docs and package configuration. It is not an exhaustive backend/security audit or whole-site coverage claim.
