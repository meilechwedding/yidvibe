## Changes

The root layout self-hosts the complete original Space Grotesk webfont. Root and shared social-image typography also uses the static 400/500/600 faces, with fonts loaded once per server module from explicit traced paths. Palette and semantic tokens carry petrol/citron/mineral/mist/canvas through public, account and admin UI. Existing accent APIs retain their keys. Shared card, form, filter, navigation and dialog surfaces use the specified radii, type scale and spacing. Primary actions and detail covers are solid petrol; the moving multicolor hero backdrop and gradient button sweep were removed. Selected text/action contrast checks cover the v8 combinations. Error states retain distinct red semantics.

No server action, query adapter, auth transport, database, migration or security settings were changed. Admin changes are source-level presentation only; no privileged resource was accessed or action executed. Existing event handlers, route destinations, validation, state and data interfaces are retained.

## Reviewer follow-up

Actual project/profile selection buttons, the tools/skills expander, calendar Today action, admin content/user filters and image remove/upload actions now use 10px corners. Clear-filter controls and remaining nav tabs share that radius. Avatar crops, switches, dots and decorative status shapes remain circular. Dashboard glance captions moved from 9px uppercase to 14px medium text with wrapping; the grid uses two columns on small phones, four from `sm`, and eight from `xl` to accommodate the larger labels.

The second independent pass found the profile's solid mist fallback assigned to `backgroundImage`, plus pill corners on overlay Save, share-banner Dismiss and owner gig-status controls. The fallback now uses `background`; those controls use the 10px radius. Six new regressions cover fallback versus uploaded covers, the radius tokens, Save's signed-out return path, actual banner dismissal and gig status selected/form state. Server actions and query interfaces are mocked; no production mutation was used.

The palette now stores 13 canonical numeric colors and 28 direct aliases. Legacy consumers and serialized metadata follow the canonical values without copying brand hex literals. The generator rejects duplicate names, invalid hex colors and alias targets outside the canonical set.
